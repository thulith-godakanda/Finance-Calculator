# Finance Calculator

A simple finance calculator developed using Python and Tkinter.

# Features

- Calculate Present Value
- Calculate Future Value
- Calculate Interest Rate
- Calculate Time Period
- Clear all entered values
- Basic input error handling

# Formula

FV = PV(1 + i)^t

# How to Run

1. Install Python.
2. Download the `finance_calculator.py` file.
3. Run:

python3 finance_calculator.py
